# Solar-Flare-Sound-Visualizer

Cool sound visualizer written in the ChucK programming language as a project for Music 256A at Stanford University. Visualizes time domain waveform and frequency as solar flares coming out of the sun.

To run, install chuck from [chuck.stanford.edu](https://chuck.stanford.edu/) and run
```
chuck main.ck
```

The code can be easily modified to visualize microphone input (just change the input_source variable in the code), but by default it runs a sin random walk that I composed.
